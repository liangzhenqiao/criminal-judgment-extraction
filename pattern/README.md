# The production pattern

`criminal_defendant_v1.3.md` is the exact text the pipeline sends as the system
message, verbatim, including its Chinese body and its snapshot header. The
reproduction run sends this file unchanged; `04_validation/tests` asserts that
the copy next to the schema
(`02_extraction/profiles/tasks/criminal_defendant_v1.3/pattern.md`) is
byte-identical.

The other tasks carry their patterns in their own profile directories
(`02_extraction/profiles/tasks/*/`), because they are not used by the
reproduction run.

`criminal_defendant_v1.3_released/` is the same prompt with its snapshot header
removed, in the form deposited with the released data.

## Glossary

- **judge frontier**: the tail of a judgment where the adjudicating roles and
  signatures sit; a *judge frontier sample* is an input cut down to that region.
- **v1.2 / v1.3**: versions of the prompt itself, not of the dataset.
- **carry-over**: a field the regex pre-fill already extracted, copied through
  unchanged instead of being generated by the model.
